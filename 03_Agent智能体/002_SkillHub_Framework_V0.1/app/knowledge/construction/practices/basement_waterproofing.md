# 地下室防水施工实践

本知识条目用于“生成地下室防水施工方案”等任务。

## 工程概况关注点

明确地下室底板、外墙和顶板的防水等级、设防体系、结构形式、地下水位及施工季节。

## 施工准备

- 核验防水材料合格证、型式检验报告和进场复验结果。
- 基层应坚实、平整、清洁，不得有明水、尖锐突起和松散物。
- 阴阳角、穿墙管、施工缝、后浇带等节点应先完成附加增强处理。

## 推荐工艺流程

基层验收 → 细部节点处理 → 涂刷基层处理剂 → 大面铺贴或涂膜施工 → 搭接与收头处理 → 质量检查 → 保护层施工。

卷材铺贴应控制搭接宽度、排气和收头密封；涂膜防水应分遍施工并控制总厚度。上下道工序之间必须完成隐蔽验收。

## 质量控制

- 材料品种、规格、性能和配合比应符合设计与产品技术要求。
- 防水层不得出现渗漏、积水、破损、空鼓和翘边。
- 细部构造应连续封闭，保护层施工不得损伤防水层。
- 完成后按项目验收方案进行蓄水或淋水检验，并保留检查记录。

## 安全文明施工

易燃材料应分类存放并远离火源；密闭空间施工应保持通风；热熔作业应履行动火审批并配置灭火器材。废料和包装物应及时分类清运。
